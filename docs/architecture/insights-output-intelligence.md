# Insights UX

Output Intelligence has two panels:

- Insights
- Manage Entries

Insights is not a free-form chat surface. It provides curated insight chips only.

## Chips and scope

- daily engineering logs: all today's Software Implementation entries
- research notes: all today's Research entries
- LinkedIn posts: selected entry if present, otherwise today's best entries
- technical blog drafts: selected entry if present, otherwise today's best entries
- architecture explainers: selected entry if present, otherwise architecture-related entries
- implementation summaries: selected entry if present, otherwise today's Software Implementation entries
- lessons learned: today's entries across both purposes

## Context used

Context used is collapsed behind an icon in the answer toolbar. It is evidence for the generated insight, not a working area.

## Manage Entries

Manage Entries owns list, search, detail, open folder, copy, and delete.
